# Leyendas Enojadas

## Descripción
Leyendas Enojadas es un juego de cartas inspirado en las leyendas y mitos tradicionales de Colombia.
Este proyecto es una página web informativa donde los jugadores pueden conocer más sobre el juego,
sus personajes basados en criaturas míticas colombianas, y las mecánicas de juego.

## Características
- Información detallada sobre el juego y sus mecánicas
- Galería de personajes basados en leyendas colombianas
- Reglas y guía de juego
- Historia y contexto de cada leyenda representada
